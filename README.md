# Gary O'Brien — Personal Portfolio

A personal portfolio site with an interactive 3D golf/cart experience built with React, Three.js, and Rapier physics.

## Tech Stack

- **React 18** + **TypeScript**
- **Three.js** — 3D rendering
- **Rapier3D** — physics engine
- **Tailwind CSS** — styling
- **Vite** — build tool
- **Cloudflare Pages** — hosting & deployment

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Automatically deployed to Cloudflare Pages on every push to `main`.
